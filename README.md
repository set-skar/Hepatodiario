# HepatoDiario

Aplicación móvil-first para registrar comidas, síntomas digestivos, agua y evacuaciones. Los datos se guardan localmente en el navegador mediante `localStorage`; no se envían a servidores.

## Probar ahora
Abrí `index.html` en un navegador moderno. Para uso habitual en Android, publicá esta carpeta en un hosting HTTPS y elegí en Chrome **⋮ > Agregar a pantalla principal**. También puede empaquetarse en APK con Android Studio/Capacitor.

## Funciones
- Diario de comidas con horario, cantidad, preparación y notas.
- Síntomas 0–5: hinchazón, gases, eructos, dolor, llenura rápida y reflujo.
- Hidratación y evacuaciones.
- Menú semanal orientativo.
- Calendario de registros.
- Estadísticas descriptivas de 7 y 30 días.
- Exportación CSV para Excel/consulta y copia completa JSON.
- Almacenamiento local sin cuenta.

## Nota clínica
No es una herramienta de diagnóstico ni reemplaza atención médica. El menú es orientativo y no trata la hepatitis autoinmune. Consultar a hepatología, especialmente si la enfermedad no está en seguimiento. No suspender ni iniciar tratamientos por esta app.

## APK
Este paquete contiene la app web funcional, no un APK compilado. Para generar APK se requiere un entorno Android SDK/Android Studio o un servicio de compilación. La opción más simple para probarla en Android es alojarla por HTTPS y agregarla a la pantalla de inicio.
